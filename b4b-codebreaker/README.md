# B4B CodeBreaker Tutor

A beginner-first AI engineering learning system built on top of the AI Engineering from Scratch curriculum and powered by Built For Breakthroughs methods.

This project turns technical AI engineering education into a guided, conversational, evidence-based learning experience for people who are new to coding.

## Core Purpose

B4B CodeBreaker Tutor helps learners move from confusion to capability by translating AI engineering concepts into:

- Smallest Useful Truths
- Grounded pop-culture bridges
- Plain-English code explanations
- CodeBreaker Challenges
- Concept Receipts
- Confusion Ledgers
- Mastery Gates
- Reachable next actions

## Core Identity

This is not just a tutor.

This is a misunderstanding remover.

It helps the learner prove understanding before moving forward.

## Source Curriculum

The system adapts the open-source AI Engineering from Scratch curriculum.

The original curriculum teaches AI engineering across 20 phases, from setup and tooling to math, machine learning, deep learning, transformers, LLMs, agents, infrastructure, ethics, and capstone projects.

This folder does not replace that curriculum.

It creates a beginner-friendly learning interface around it.

## Project Modules

### `/gpt`

Custom GPT instructions, setup files, testing prompts, and quality checklists.

### `/b4b-method`

The learning philosophy and instructional framework.

### `/codebreaker-challenges`

Gamified proof-of-understanding missions.

### `/pop-culture-bridges`

Accurate analogy systems using familiar cultural references.

### `/learner-system`

Templates for learner profiles, concept receipts, confusion ledgers, and progress tracking.

### `/prompts`

Reusable prompts for teaching, debugging, quizzing, and challenge generation.

### `/exports`

Ready-to-upload packs for Custom GPT, Notion, PDFs, and future formats.

## Learning Doctrine

The learner does not need the whole mountain at once.

They need the first handle.

Then the next.

Then the next.

B4B CodeBreaker Tutor exists to turn AI engineering from a wall of symbols into a sequence of reachable actions.

## Core Loop

1. Name the thing.
2. Reduce it to the Smallest Useful Truth.
3. Explain why it exists.
4. Build a pop-culture bridge.
5. Explain where the analogy works.
6. Explain where the analogy stops.
7. Teach concept before code.
8. Translate code plainly.
9. Give a tiny challenge.
10. Capture evidence.

## CodeBreaker Challenges

Every concept can become a lock.

The learner opens the lock by producing evidence:

- Decode
- Predict
- Fix
- Modify
- Explain
- Connect
- Refactor
- Boss Lock
