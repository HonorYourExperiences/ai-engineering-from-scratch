# Product Brief: B4B CodeBreaker Tutor

## One-Line Definition

B4B CodeBreaker Tutor is a beginner-first AI engineering learning system that turns the AI Engineering from Scratch curriculum into a guided, conversational, evidence-based learning experience.

## Product Thesis

People do not usually fail technical learning because they lack intelligence.

They fail because the system skips translation, evidence, and emotional friction.

B4B CodeBreaker Tutor closes that gap by turning technical concepts into Smallest Useful Truths, pop-culture bridges, CodeBreaker Challenges, and proof-of-understanding artifacts.

## Target Learner

A curious beginner who wants to understand AI engineering but does not yet know:

- Coding languages
- Python
- Terminal commands
- GitHub
- Math notation
- Machine learning vocabulary
- AI engineering workflows

## Core Promise

The learner will not be rushed through the curriculum.

They will be guided from confusion to capability through reachable actions and visible evidence.

## Product Pillars

### 1. Misunderstanding Removal

Every concept is reduced, translated, bridged, and rebuilt.

### 2. Concept Before Code

The learner understands the purpose and mechanism before touching syntax.

### 3. Pop-Culture Precision

References are used as bridges, not decorations. Every analogy explains where it works and where it stops.

### 4. Evidence-Based Learning

Understanding is confirmed through proof, not vague agreement.

### 5. CodeBreaker Challenges

Every concept can become a lock. The learner unlocks it through explanation, prediction, modification, debugging, or transfer.

## MVP Scope

The MVP supports:

- Custom GPT instructions
- Expanded GPT README
- CodeBreaker Challenge framework
- B4B learning method documentation
- Concept Receipt templates
- Confusion Ledger templates
- Quality testing prompts

## Non-Goals for MVP

The MVP does not attempt to:

- Replace the original curriculum
- Build a full app
- Automate learner memory across platforms
- Generate every challenge for every phase
- Teach all 20 phases at once

## Future Direction

This system may expand into:

- A paid Custom GPT asset
- A beginner AI engineering workbook
- A CodeBreaker challenge library
- A Notion learning dashboard
- A cohort-based course companion
- A web app with progress tracking
- A B4B-powered learning operating system

## Success Criteria

The system is working if the learner can:

1. Explain technical concepts in plain language.
2. Identify where code expresses those concepts.
3. Predict small code behavior.
4. Fix beginner errors without panic.
5. Produce Concept Receipts as learning evidence.
6. Move through the curriculum with less fear and more proof.
