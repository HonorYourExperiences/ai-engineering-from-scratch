# B4B CodeBreaker Tutor Roadmap

## Stage 0: Project Skeleton

Create the first working structure inside `b4b-codebreaker/`.

Deliverables:

- README
- Product brief
- Roadmap
- GPT instruction files
- B4B method files
- CodeBreaker templates
- Learner evidence templates

## Stage 1: Custom GPT MVP

Build the first usable Custom GPT asset.

Deliverables:

- Short Custom GPT instructions
- Expanded GPT README
- Conversation starters
- Test prompts
- Quality checklist

Success marker:

The GPT can teach Phase 0, Lesson 1 to a true beginner without assuming coding knowledge.

## Stage 2: CodeBreaker Challenge MVP

Create the first challenge system.

Deliverables:

- Lock types
- Difficulty levels
- Challenge template
- Boss Lock template
- Starter beginner coding locks
- Starter AI concept locks

Success marker:

The learner can prove understanding through explaining, predicting, fixing, modifying, or connecting concepts.

## Stage 3: Learner Evidence System

Create visible learning artifacts.

Deliverables:

- Concept Receipt template
- Confusion Ledger template
- Session Closeout template
- Progress Map template
- Mastery Gates

Success marker:

Every learning session can end with evidence of progress.

## Stage 4: Phase 0 Learning Path

Build the beginner onboarding path.

Deliverables:

- Dev environment guide
- GitHub guide
- Terminal guide
- Python intro guide
- File and folder guide
- Error translation guide

Success marker:

A beginner can enter the repo without being buried by invisible prerequisites.

## Stage 5: Phase 1 Learning Path

Build the beginner math bridge.

Deliverables:

- Vector bridge
- Matrix bridge
- Probability bridge
- Gradient bridge
- Distance bridge
- Optimization bridge

Success marker:

The learner can explain math concepts in human, technical, code, and system terms.

## Stage 6: Productization

Package the system as a premium learning asset.

Deliverables:

- GPT upload pack
- Notion outline
- PDF workbook outline
- Product positioning page
- User onboarding flow

Success marker:

B4B CodeBreaker Tutor becomes a structured learning product, not just a prompt.
