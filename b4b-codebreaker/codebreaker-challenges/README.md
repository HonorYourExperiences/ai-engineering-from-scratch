# CodeBreaker Challenges

CodeBreaker Challenges are the proof-of-understanding system for B4B CodeBreaker Tutor.

Each challenge turns a concept into a lock.

The learner opens the lock by producing evidence.

## Purpose

CodeBreaker Challenges transform passive learning into active decoding.

The goal is not speed.

The goal is clarity.

## Challenge Types

- Decode: explain what code or a concept means.
- Predict: predict what code will do.
- Fix: identify and correct an error.
- Modify: change code intentionally.
- Explain: explain a concept in the learner’s own words.
- Connect: connect the concept to a larger AI system.
- Refactor: improve messy or repetitive code.
- Analogy: explain where a learning analogy works and where it stops.
- Boss Lock: combine multiple concepts in one challenge.

## Difficulty Levels

1. Spark Lock: recognize and identify.
2. Signal Lock: predict and explain.
3. Circuit Lock: modify and apply.
4. System Lock: transfer to a new context.
5. Architect Lock: combine multiple ideas.
6. Boss Lock: integrate several concepts under pressure.

## Core Rule

Do not reveal the solution immediately.

Offer hints first.

Let the learner attempt the lock.

After the attempt, explain what worked. If the answer is incorrect, diagnose the misunderstanding and make the next step smaller.

## Every Challenge Should Include

- Challenge name
- Lock type
- Difficulty level
- Concept
- Smallest Useful Truth
- Pop-Culture Bridge
- Where the analogy works
- Where the analogy stops
- Mission
- The Lock
- Hints
- Break Condition
- After Unlock summary
