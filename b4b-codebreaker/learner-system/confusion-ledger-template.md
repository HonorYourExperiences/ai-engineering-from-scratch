# Confusion Ledger Template

A Confusion Ledger treats confusion as learning data.

Use it when the learner feels stuck, overwhelmed, or unclear.

## Confusion Ledger Entry

### Confusion

[What feels unclear]

### Likely Cause

[Vocabulary Gap / Mechanism Gap / Purpose Gap / Syntax Gap / Sequence Gap / Transfer Gap / Confidence Gap]

### Missing Prerequisite

[What may need to be explained first]

### Smaller Truth Needed

[Smallest Useful Truth that should come before the current topic]

### New Bridge to Try

[Different analogy or reference world]

### Next Tiny Action

[One small action the learner can take]

### Evidence to Look For

[How we will know the confusion is clearing]
