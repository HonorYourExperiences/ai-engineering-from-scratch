# Phase 0 Starter Path: Setup & Tooling

## Purpose

Phase 0 is the learner's first doorway into AI Engineering from Scratch.

For a true beginner, setup is not just setup.

It is the moment where invisible prerequisites become visible:

- What is code?
- What is Python?
- What is GitHub?
- What is terminal?
- What is a file?
- What is a folder?
- What is a command?
- What is an error?

This guide turns Phase 0 into a beginner-safe onboarding path using B4B methods and CodeBreaker Challenges.

## Phase 0 Doctrine

Before the learner builds AI, they need to understand the workshop.

The goal is not to master every tool immediately.

The goal is to know what each tool is, why it exists, and how to take the first safe action with it.

## Recommended Teaching Order

1. What is code?
2. What is a programming language?
3. What is Python?
4. What is a file?
5. What is a folder?
6. What is GitHub?
7. What is terminal?
8. What is a command?
9. What is an error?
10. First setup flow
11. First CodeBreaker review

# 1. What Is Code?

## Smallest Useful Truth

Code is written instruction for a machine.

## Why It Matters

AI systems are built from instructions. Before the learner can understand AI, they need to understand that code is how humans tell computers what to do.

## Pop-Culture Bridge

Code is like a spellbook in Harry Potter, but stricter.

The computer does not understand vibes, intention, or almost-right instructions.

It follows exactly what is written.

## Where the Analogy Works

Both code and spells require structured instructions to produce a result.

## Where the Analogy Stops

Code is not magic. It is a set of precise rules interpreted or executed by a computer.

## Concept Before Code

A computer does not know what the learner wants.

Code is the written bridge between human intention and machine action.

## CodeBreaker Lock: Code Decoder 001

### Lock Type

Explain

### Difficulty

Spark Lock

### Mission

Explain what code is in your own words.

### The Lock

Complete the sentence:

Code is ______ for a machine.

### Hint 1

It tells the machine what to do.

### Break Condition

The learner explains that code is written instruction for a machine.

### After Unlock

The learner has proved they understand code as instruction, not mystery.

# 2. What Is a Programming Language?

## Smallest Useful Truth

A programming language is a rule system for giving instructions to a computer.

## Why It Matters

Computers need instructions written in a structure they can interpret.

Python, TypeScript, Rust, and Julia are different rule systems for writing those instructions.

## Pop-Culture Bridge

A programming language is like bending in Avatar: The Last Airbender.

Waterbending, earthbending, firebending, and airbending all move energy differently, but each has rules, forms, and techniques.

## Where the Analogy Works

Each programming language has its own style and rules for shaping action.

## Where the Analogy Stops

Programming languages do not contain spiritual power. They are formal systems for writing machine instructions.

## CodeBreaker Lock: Language Lens 001

### Lock Type

Decode

### Difficulty

Spark Lock

### Mission

Name one reason programming languages exist.

### The Lock

Why can't we just tell the computer what we mean casually?

### Hint 1

Computers need structured instructions.

### Break Condition

The learner explains that programming languages give humans a structured way to communicate instructions to computers.

# 3. What Is Python?

## Smallest Useful Truth

Python is a readable programming language often used for data, automation, and AI.

## Why It Matters

AI Engineering from Scratch uses multiple languages, but Python is the best starting point for most beginners because it is readable and common in AI work.

## Pop-Culture Bridge

Python is like the common tongue in a fantasy world.

It may not be the only language, but many travelers, builders, and scholars know how to use it.

## Where the Analogy Works

Python is widely used and beginner-friendly compared with many other languages.

## Where the Analogy Stops

Python is not universal. Some systems use other languages for speed, safety, interfaces, or production needs.

## CodeBreaker Lock: Python Passport 001

### Lock Type

Explain

### Difficulty

Spark Lock

### Mission

Explain why Python is a good first language for AI learning.

### The Lock

Complete the sentence:

Python is useful for AI beginners because ______.

### Hint 1

Think readability and AI ecosystem.

### Break Condition

The learner explains that Python is readable and commonly used in data and AI work.

# 4. What Is a File?

## Smallest Useful Truth

A file is a container for instructions or information.

## Why It Matters

Code usually lives in files. Data can live in files. Notes, outputs, and configuration can all live in files.

## Pop-Culture Bridge

A file is like a scroll in a wizard archive.

Each scroll holds specific instructions, records, or knowledge.

## Where the Analogy Works

Both files and scrolls store information that can be opened, read, and used.

## Where the Analogy Stops

Files are digital structures stored by a computer, not physical objects.

# 5. What Is a Folder?

## Smallest Useful Truth

A folder organizes related files.

## Why It Matters

Repos use folders to keep lessons, code, docs, outputs, scripts, and assets organized.

## Pop-Culture Bridge

A folder is like Batman's utility belt compartments.

The tools are easier to find because they are grouped by purpose.

## Where the Analogy Works

Folders organize things so the user can find and use them.

## Where the Analogy Stops

A folder does not physically hold objects. It organizes digital paths to files.

# 6. What Is GitHub?

## Smallest Useful Truth

GitHub is a shared library and version-history system for code.

## Why It Matters

The AI Engineering from Scratch curriculum lives in a GitHub repo. The learner needs to understand GitHub as a place where code, docs, history, and collaboration can live.

## Pop-Culture Bridge

GitHub is like the Jedi Archives for code, except people can also update the records and track what changed.

## Where the Analogy Works

GitHub stores organized knowledge and makes it accessible.

## Where the Analogy Stops

GitHub is not only a library. It also tracks versions, changes, issues, collaboration, and project history.

## CodeBreaker Lock: GitHub Gate 001

### The Lock

GitHub helps developers store, share, and track changes to ______.

# 7. What Is Terminal?

## Smallest Useful Truth

Terminal is a text-based control panel for your computer.

## Why It Matters

Many setup steps happen in terminal. The learner may need terminal to run Python files, install tools, navigate folders, and check outputs.

## Pop-Culture Bridge

Terminal is like the command console on a spaceship.

Instead of clicking buttons, the pilot types precise instructions.

## Where the Analogy Works

Terminal accepts commands and gives responses.

## Where the Analogy Stops

Terminal is not automatically intelligent. It only runs commands the system understands.

### Break Condition

# 8. What Is a Command?

## Smallest Useful Truth

A command is an instruction typed into terminal.

## Why It Matters

Commands let the learner ask the computer to do specific tasks: move into a folder, run a file, install a package, or show information.

## Pop-Culture Bridge

A command is like giving Iron Man's suit a specific instruction.

The instruction has to match what the system understands.

## Where the Analogy Works

Both commands and suit instructions trigger specific actions.

## Where the Analogy Stops

A terminal command does not understand intent beyond its exact syntax.

# 9. What Is an Error?

## Smallest Useful Truth

An error is the machine telling you where its understanding broke.

## Why It Matters

Beginners often treat errors as proof they failed. In AI engineering, errors are diagnostic signals.

## Pop-Culture Bridge

An error is like a warning light on a car dashboard.

It does not mean the driver is worthless.

It means something needs attention.

## Where the Analogy Works

Both errors and warning lights point toward a problem.

## Where the Analogy Stops

Code errors can be very specific and may require reading the message, file path, and line number.

## CodeBreaker Lock: Error Decoder 001

### Lock Type

Explain

### Difficulty

Spark Lock

### Mission

Reframe an error as information.

### The Lock

Complete the sentence:

An error is not proof that I am bad at coding. It is ______.

### Hint 1

It is a clue.

### Break Condition

The learner explains that an error is a clue or signal about where the machine's understanding broke.

# 10. First Setup Flow

## Goal

The learner should understand the purpose of a basic setup flow before doing it.

## Setup Flow in Plain English

1. Get the project.
2. Open the project folder.
3. Make sure Python can run.
4. Run a small file.
5. Read the output.
6. If there is an error, translate it.

## B4B Translation

This is not random technical ritual.

It is workshop preparation.

Before building AI, the learner is checking that the tools, workspace, and first path are usable.

## Pop-Culture Bridge

This is like a hero checking their gear before the first mission.

Cape tied. Boots on. Utility belt loaded. Snack packed for the journey.

## Where the Analogy Works

Setup ensures the learner has the tools needed before starting the mission.

## Where the Analogy Stops

Software setup is not heroic by itself. It is practical preparation that prevents later friction.

# 11. Phase 0 Starter CodeBreaker Review

## Boss Lock: The Workshop Door

### Combined Concepts

- Code
- Python
- File
- Folder
- GitHub
- Terminal
- Command
- Error

### Difficulty

Boss Lock

### Mission

Explain the beginner setup workflow in plain English.

### The Lock

A learner says:

“I opened GitHub, downloaded the repo, opened terminal, typed a command, and got an error. I think I broke everything.”

Explain what probably happened using the concepts from this guide.

### Available Clues

#### Clue 1

GitHub stores the project. Terminal runs typed commands.

#### Clue 2

An error is a clue, not a catastrophe.

#### Clue 3

The learner may be in the wrong folder, missing Python, or using a command the system does not understand.

### Break Condition

The Boss Lock is solved when the learner can explain:

1. GitHub stores the repo.
2. Files and folders organize the project.
3. Terminal accepts commands.
4. Python runs Python files.
5. Errors are diagnostic clues.
6. The next action is to read the error and check one thing at a time.

### After Unlock

The learner proved they understand the beginner setup environment as a system, not a pile of random tools.

# Phase 0 Tutor Notes

## Watch For These Misunderstandings

### Vocabulary Gap

The learner may not know what repo, terminal, command, file path, or Python means.

### Sequence Gap

The learner may know words individually but not the order of setup actions.

### Confidence Gap

The learner may interpret errors as personal failure.

## Recommended Tutor Response

Slow down.

Name the tool.

Explain why it exists.

Show one tiny action.

Ask for one evidence check.

## First Evidence Checks

Use these before moving deeper:

1. Explain what code is.
2. Explain what GitHub stores.
3. Explain what terminal does.
4. Explain what a command is.
5. Explain what an error means.
6. Explain why files and folders matter.

## Completion Criteria

The learner is ready to continue Phase 0 when they can explain:

- Code is written instruction for a machine.
- Python is a readable programming language often used for AI.
- Files hold instructions or information.
- Folders organize files.
- GitHub stores and tracks code projects.
- Terminal accepts typed commands.
- Commands are instructions typed into terminal.
- Errors are clues about where understanding broke.
