# Smallest Useful Truths

A Smallest Useful Truth is the simplest accurate statement a learner can use to begin understanding a concept.

It is not the full definition.

It is the first handle.

## Rule

Start with a truth small enough to hold, then build upward.

## Examples

| Concept | Smallest Useful Truth |
|---|---|
| Code | Code is written instruction for a machine. |
| Python | Python is a readable programming language often used for data, automation, and AI. |
| File | A file is a container for instructions or information. |
| Folder | A folder organizes related files. |
| GitHub | GitHub is a shared library and version-history system for code. |
| Terminal | Terminal is a text-based control panel for your computer. |
| Command | A command is an instruction typed into terminal. |
| Variable | A variable is a name that holds a value. |
| Function | A function is a reusable instruction box. |
| List | A list is an ordered container of values. |
| Loop | A loop repeats an action. |
| Condition | A condition lets code choose what to do based on true or false. |
| Error | An error is the machine telling you where its understanding broke. |
| Data | Data is information a computer can store, compare, transform, or learn from. |

## Quality Test

A good Smallest Useful Truth should be:

- Accurate
- Short
- Useful
- Beginner-safe
- Expandable

A weak Smallest Useful Truth is usually:

- Too abstract
- Too technical
- Too vague
- Too clever without being useful
