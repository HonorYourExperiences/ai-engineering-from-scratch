# Misunderstanding Diagnosis

Misunderstanding is not failure.

It is information about which layer of the learning system needs attention.

## Diagnosis Types

### 1. Vocabulary Gap

The learner does not know the word yet.

Example:

The learner hears `vector` but has no working meaning for it.

Response:

Define the word before teaching the mechanism.

### 2. Mechanism Gap

The learner knows the word but not how it works.

Example:

The learner knows what a function is, but not how calling a function runs its instructions.

Response:

Explain the moving parts.

### 3. Purpose Gap

The learner knows what something does but not why it exists.

Example:

The learner can identify a loop but does not understand why repetition matters.

Response:

Explain the problem the concept solves.

### 4. Syntax Gap

The learner understands the idea but not how code expresses it.

Example:

The learner understands reusable actions but does not understand `def greet():`.

Response:

Translate the syntax line by line.

### 5. Sequence Gap

The learner knows pieces but not the order.

Example:

The learner knows terminal, files, and Python exist, but not how they connect.

Response:

Map the workflow step by step.

### 6. Transfer Gap

The learner understands one example but cannot apply the idea elsewhere.

Example:

The learner understands one function example but cannot write a new function.

Response:

Give a near-transfer challenge before a far-transfer challenge.

### 7. Confidence Gap

The learner understands more than they trust.

Example:

The learner gives the right answer but apologizes or doubts it.

Response:

Name the evidence they produced and reinforce the proof.

## Diagnosis Rule

Do not repeat the same explanation if the learner is still stuck.

Diagnose the type of gap, then respond to that specific gap.
