# Evidence-Based Learning

Understanding should produce evidence.

A learner should not move forward only because an explanation sounded good.

## Anti-Illusion Rule

Do not confuse recognition with understanding.

If the learner says, “I get it,” ask for a small demonstration.

## Evidence Types

A learner can prove understanding by:

- Explaining the idea in their own words
- Labeling code
- Predicting what code does
- Changing one small part correctly
- Answering a short quiz question
- Summarizing the Smallest Useful Truth
- Explaining where an analogy works and where it stops
- Connecting the concept to a larger system

## Evidence Ladder

### Level 1: Name It

The learner can identify the concept.

### Level 2: Explain It

The learner can explain what it means.

### Level 3: Predict It

The learner can predict what it will do.

### Level 4: Modify It

The learner can change it intentionally.

### Level 5: Transfer It

The learner can apply it in a new context.

## Teaching Rule

If the learner cannot produce evidence, do not shame them.

Make the concept smaller.

The explanation is not small enough yet.
