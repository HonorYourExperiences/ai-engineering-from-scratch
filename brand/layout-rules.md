# Layout Rules

## Default WonderCard ratio
- Default card ratio is **2:3 vertical**.
- Production canvas: 800 × 1200 px for screen previews.
- Preserve editable text, panels, icons, and image layers.

## Step-Into WonderCard ratio
- Step-Into WonderCards may use a **3:5 vertical** ratio.
- Production canvas: 900 × 1500 px for screen previews.
- Use the taller ratio for journey, scene, or portal-style cards that need extra vertical storytelling space.

## Safe areas
- Keep core text inside a 6% inset safe area.
- Keep footer brand marks inside a dedicated editable footer band.
